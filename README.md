# poc

A minimal Proof of Concept (PoC) repository for experimenting and demonstrating small ideas.

## Overview

This repository is intended to hold short prototypes, experiments, and example code. Use it to sketch ideas, reproduce bugs, or share minimal demos.

## Repository structure

- `src/` - source code and prototypes
- `docs/` - documentation and notes
- `examples/` - example usage and demos

Adjust these folders to match the actual contents of the repository.
